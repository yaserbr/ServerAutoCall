AutoCall User Guide

How to Send a New Command

  1. Log in to the website.
  2. Add your device with Add Device if it is not listed yet.
  3. Select the target device from the device menu at the top of the page.
  4. Go to Command Center and choose the command type you need.
  5. Enter the required details, such as the phone number, message, URL, or app name.
  6. Press the command send button, then track its status in the Commands table.

Tips for New Users

  1. If your device does not appear, press Refresh or reopen the AutoCall app on the phone.
  2. Use the scheduled time only when you want the command to run later. Leave it empty to run now.
  3. After sending a command, watch the status: Pending means waiting for the device, and Done means completed.
  4. Use Refresh in the Commands table when you need a manual update.

Available Commands

  1. Send Call: Place a call to a selected number. Phone number is who to call, Call duration ends the call after that many seconds, Schedule Time runs it later, and Notes are optional.
  2. Send SMS: Send a text message to a Phone number, SMS message is the text to send, Schedule Time sends it later, and Notes are optional
  3. Auto Answer: Turn auto-answer On / Off and set the hangup duration, controls whether the phone answers automatically, Auto hangup seconds controls when it ends the call.

More Commands

  1. WebView Commands: Open a URL on the phone or close the open web page.
  2. Open App: Open an app by name or package name.
  3. Return to AutoCall: Bring the phone back to the AutoCall app.
  4. Download Data: Start a data download test using the size you choose.
  5. Activate eSIM: Send an eSIM activation code to the device.

Faster Ways to Work

  1. Collections: Run several commands as one sequence, such as opening a URL, waiting, then sending an SMS.
  2. AI Agent Assistant: Type a natural request, such as Call Mohammed or Send SMS to Ali.
  3. Address Book: Save contacts so you can use names instead of typing numbers every time.
  4. Screen Mirror: Click the mirror icon next to a device to view and control the phone when needed.
  5. Clear Commands: Clears the command history table only. It does not send a new command to the device.
